# 가이드

[English](index.md)

ARIA를 배포하고 확장하고 운영하는 팀을 위한 안내서입니다.

## 설정과 확장

- [시작하기](getting-started.ko.md): 설정, 배포 환경에 웹 앱 연결, 쇼핑몰 이름 변경
- [통합](integrations.ko.md): 설정, 로그인(관리형 Cognito 또는 자체 IdP), 카탈로그 공급자와 자체 카탈로그 사용, Gateway 대상과 모드, Memory, Guardrail, 사용자 지정 헤더
- [로컬 도구 추가](add-a-local-tool.ko.md): 에이전트 안에서 실행되는 도구를 작성, 등록, 허용, 테스트하는 방법
- [Gateway 등록](gateway-onboarding.ko.md): OpenAPI API, API Gateway 스테이지, Lambda 함수, MCP 서버를 Gateway 뒤에 두는 방법

## 배포와 운영

- [출시 설정](launch-settings.ko.md): 쇼핑객이 스테이지를 쓰기 전에 정할 설정, Prod가 강제하는 것, 설정으로 정할 수 없는 결정
- [릴리스](release.ko.md): 로컬 검사, 사전 점검, 검토된 배포, 롤백, 인수 검사, 웹 앱 호스팅, 컨테이너 빌드
- [테스트](testing.ko.md): 테스트 묶음과 다루는 범위, 배포 후 실제 환경 검사
- [운영](operations.ko.md): 관측 지표, 사고 초기 분석, 비용, Memory와 개인 식별 정보, 카탈로그 런북과 인덱싱, 자격 증명 교체, 도구 문제 해결
- [평가](evaluations.ko.md): 온라인 AgentCore Evaluations와 데이터셋 실행
- [변경 기록](changelog.ko.md): 릴리스 노트 작성 방법
