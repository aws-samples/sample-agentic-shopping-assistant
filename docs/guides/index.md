How-tos for teams deploying, extending and operating ARIA.

## Set up and extend

- [Getting started](getting-started.md): set up, run the web app against a deployment, rename the storefront.
- [Integrations](integrations.md): configuration, sign-in (managed Cognito or your IdP), catalog providers and bringing your own catalog, Gateway targets and modes, Memory, the guardrail, custom headers.
- [Add a local tool](add-a-local-tool.md): write, register, allow and test a tool that runs in the agent.
- [Gateway onboarding](gateway-onboarding.md): put an OpenAPI API, API Gateway stage, Lambda function or MCP server behind the Gateway.

## Ship and run

- [Launch settings](launch-settings.md): the settings to decide before shoppers reach a stage, what Prod enforces, and the decisions no setting covers.
- [Release](release.md): local gates, preflight, the reviewed deployment, rollback, acceptance, hosting the web app, container builds.
- [Testing](testing.md): the test suites, what they cover, and the live checks after a deploy.
- [Operations](operations.md): signals, triage, cost, Memory and PII, the catalog runbook and indexing, credential rotation, tool troubleshooting.
- [Evaluations](evaluations.md): online AgentCore Evaluations and dataset runs.
- [Changelog](changelog.md): how to write release notes.
